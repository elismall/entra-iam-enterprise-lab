# Small Studios - Company Overview

## Company

Small Studios is a fictional technology company used to demonstrate enterprise Identity and Access Management practices using Microsoft Entra ID.

## Environment

Small Studios operates primarily in a Microsoft cloud environment.

Identity Provider:
Microsoft Entra ID

## Departments

- Information Technology
- Human Resources
- Finance
- Sales
- Operations

## IAM Objectives

- Centralize identity management
- Implement role-based access control
- Enforce least privilege
- Require multi-factor authentication
- Automate user provisioning and deprovisioning
- Implement Joiner-Mover-Leaver processes
- Secure privileged accounts
- Monitor identity-related activity
