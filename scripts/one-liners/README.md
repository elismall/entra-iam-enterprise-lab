# PowerShell One-Liners

## Publish Screenshot

Template:

`.\scripts\Publish-Screenshots.ps1 -Name "PHOTO-NAME" -Category "FOLDER"`

Example:

`.\scripts\Publish-Screenshots.ps1 -Name "groups-01" -Category "groups"`
